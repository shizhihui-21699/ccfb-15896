# 电力现货市场报价串通与持留行为识别

面向省级电力交易中心/监管机构的监测工具。用可解释、可复核的统计方法,在负荷、燃料、
新能源剧烈波动的背景下,识别发电企业的**报价串通**与**策略性持留**,并给出可讲清楚的证据链。

## 核心思路:先剥离共同市场条件,再看残差

电价本来就会随负荷、燃料成本、新能源出力同向波动,**"两家报价同步"几乎没有证据力**。
本项目用一个对照实验说明了这一点(见报告第一节):

| 相关性口径 | 串通集团内部 | 非串通机组之间 |
|---|---|---|
| 原始报价 | 0.57 | 0.54 |
| 基本面残差 z | 0.86 | 0.00 |

所以方法分三步:

1. **基本面残差模型**(`baseline.py`)
   对每台机组用**分位数回归**(τ=0.5)拟合竞争性报价函数
   `bid = f(边际成本, 紧张度, 新能源占比, 时段谐波, 季节谐波, 周末)`,
   残差做稳健标准化得到 z 分数。用中位数回归而非最小二乘,避免少数抬价样本污染基准线。

2. **串通识别**(`collusion.py`)
   在**市场条件分层**内,检验两台机组是否**同期出现无法由基本面解释的抬价**。
   - 分层(紧张度分位 × 季节)吸收共同条件;
   - 层内置换检验得到零分布,回答"若两家只是各自随市场波动,同期抬价会有多少";
   - BH-FDR 控制误报,并用**抬价倍数 lift**给效应量;
   - 显著边构成网络 → 连通分量得到候选集团;识别**轮值领导者**(轮流坐庄)。

3. **持留识别**(`withholding.py`) —— 解决"真检修 vs 故意停运"
   关键变量是**外生价格影响 Δp**:假设该机组始终可用,计算"它此刻停运能把出清价抬高多少"。
   Δp 只由其他机组状态与负荷决定,与自身是否停运无关,因此不受反向因果污染。
   真实故障无选择性;策略持留则**集中发生在 Δp 大的时刻**。
   在 Δp 档内、按紧张度分层比较停运率,二项检验 + 实质门槛(超额小时、租金损失)。

4. **影响量化**(`impact.py`):反事实再出清,估算价格降幅与用户侧额外成本。

## 快速开始

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# 重新仿真并跑完整分析（生成 data/ 与 outputs/）
.venv/bin/python -m power_monitor.run --simulate

# 用已有 data/ 只跑分析
.venv/bin/python -m power_monitor.run
```

输出在 `outputs/`:
- `监管分析报告.md` —— 主报告(含图表链接与证据链说明)
- `fig1..6*.png` —— 图表
- `collusion_pairs.csv` / `withholding_summary.csv` —— 可复核的中间量
- `counterfactual_hourly.csv` / `impact_summary.csv` —— 反事实结果
- `evaluation.json` —— 基于仿真真值的检出/误报评估(仅方法验证)

## 目录

```
power_monitor/
  config.py      市场参数与识别阈值(集中管理,便于审计)
  simulate.py    现货市场仿真器(内置已知真值,用于方法验证)
  data.py        数据装载 + merit-order 出清引擎
  baseline.py    基本面残差模型(分位数回归)
  collusion.py   串通识别(分层置换检验 + 网络 + 轮值)
  withholding.py 持留识别(外生 Δp + 条件停运率)
  impact.py      反事实影响量化
  evaluate.py    真值评估
  plots.py       图表
  run.py         主流程 + 报告生成
tests/           单元/集成测试
```

## 重要声明

- 本工具输出是**统计异常线索,不构成违法认定**。串通需结合通讯记录、结构性关联等协调性证据;
  持留需核查检修工单、备件领用、修复时长、人员到岗等真实资料。
- 反事实价格影响依赖 merit-order 出清模型(无网络约束、无机组组合/爬坡),引用前应做敏感性分析。
- 仿真数据用于**验证方法**,真实数据需重新校准阈值(见 `config.py`)。
